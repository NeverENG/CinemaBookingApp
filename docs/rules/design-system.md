## Color System

```css
:root {
    /* Primary - 金黄色 (品牌主色) */
    --primary: oklch(0.852 0.199 91.936);
    --primary-hover: oklch(0.75 0.18 91.936);
    --primary-glow: oklch(0.852 0.199 91.936 / 0.4);

    /* Dark Background */
    --bg-dark-start: #0a0a0a;
    --bg-dark-end: #1a1a1a;

    /* Light Background */
    --bg-light: #ffffff;
    --bg-input: #f8f9fc;

    /* Text */
    --text-primary: #1a1a2e;
    --text-secondary: #64748b;
    --text-light: #ffffff;
    --text-muted: #94a3b8;

    /* Border */
    --border: #e2e8f0;
    --border-focus: var(--primary);
}
```
