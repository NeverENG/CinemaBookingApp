# 实验报告固定规则

1. 以用户提供的初始 DOCX 模板为排版基准，不随意更换风格或重建文档架构。
2. 封面、任务书、字体、字号、页眉页脚和页码沿用任务格式；允许为消除正文留白而调整分页约束、图文位置、段落顺序及图片的合理尺寸，但不得拉伸图片或破坏章节层级。
3. 正文单页留白不得超过 30%；学校规定的封面页按原模板保留。
4. 优先通过删除重复文字、纠正内容错位、解除错误的整组锁页、合并重复代码节选和调整内容顺序减少空白；只有确实改善页面密度时才等比例调整图片。
5. 不保留完全重复的段落；术语、章节编号、图号和代码编号必须统一。
6. 每次修改后重新打开或渲染 DOCX，逐页检查章节顺序、页面密度、图片清晰度和末页留白。
