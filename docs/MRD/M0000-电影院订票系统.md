## 1. 市场分析

- **TAM**：高校周边观影人群 + 社区影院，规模按校园 1~5 万人估算。
- **SAM/SOM**：校内学生及教职工；首期以单个影院试点。
- **PEST**：政策上无特殊门槛；经济上学生价格敏感；社会层面社交观影需求稳定；技术层面移动端/小程序普及。
- **进入壁垒**：无牌照门槛，但信任与排片资源是关键；通过本地化运营突破。

## 2. 用户分析

**画像 A：观影学生（核心用户）**
- 特征：18~25 岁，价格敏感，偏好实时选座、优惠和会员权益。
- 痛点：热门场次抢不到好座位、付款后出票不放心、优惠规则复杂。
- 期望：选座实时、支付可靠、优惠简单、积分不贬值。

**画像 B：影院运营管理员**
- 特征：需要快速完成排片、调价、对账和票房统计。
- 痛点：手工表格易错、无法实时知道销售情况。
- 期望：排片可视、票价灵活、大盘自动汇总。

## 3. 竞品分析

直接竞品：猫眼、淘票票（票务+营销）；间接竞品：线下柜台、团购平台。

**机会点**：校园/社区场景的轻量私有化方案，把「选座锁座、支付幂等、优惠券+积分闭环」做到数据库级可靠，同时保持部署成本极低。

## 4. 产品需求与策略建议

- **Top 5 核心能力**：
  1. 实时选座 + 数据库级锁座（不超卖）；
  2. 订单支付 + 模拟回调 + 幂等入账；
  3. 订单退款 + 积分扣回（无虚拟货币）；
  4. 优惠券 + 会员积分（防数值膨胀）；
  5. 票房数据大盘（时间/影片/影院过滤）。

- **路线图**：W1 文档+数据模型冻结 → W2 账号与内容管理 → W3 选座/订单/支付（核心）→ W4 营销/大盘/部署联调。
